# 指标字典

> 面试高频问题：「你的 GMV 是怎么算的？」—— 每个指标的口径必须能脱口而出。

## 一、经营指标（来源: fact_order）

| 指标 | 函数 | 定义 / 口径 | 业务用途 |
|------|------|------------|---------|
| GMV | `gmv()` | Σ(数量×单价)，**只统计 Shipped 订单** | 店铺规模 |
| 订单数 | `order_count()` | 已发货订单数 | 需求规模 |
| 销量 | `units_sold()` | 已发货件数 | 备货参考 |
| 客单价 AOV | `aov()` | GMV ÷ 已发货订单数 | 定价与利润 |
| 日均 GMV | `avg_daily_gmv()` | GMV ÷ 有销售的天数 | 现金流估算 |
| 月度趋势 | `monthly_trend()` | 按月聚合 GMV/订单/销量 + GMV 环比 | 增长诊断 |
| 周订单分布 | `weekday_analysis()` | 一周各天平均订单量 | 运营排期 |
| 取消率 | `cancellation_rate()` | Cancelled 订单占**全量**订单比 | 库存/供应链健康 |
| 复购SKU占比 | `repeat_purchase_sku_ratio()` | 出现 ≥2 次购买的 SKU 占比（无客户维度的代理口径） | 产品粘性 |
| 品类结构 | `category_breakdown()` | 各品类 GMV / 订单 / 占比 | 品类聚焦决策 |
| 价格带分布 | `price_band_distribution()` | 订单单价分桶（$0-15 / 15-30 / 30-60 / 60+） | 定价策略 |
| 头部集中度 | `top_sku_concentration()` | TOP10 SKU 的 GMV 占比 | 爆款依赖风险 |

## 二、市场竞品指标（来源: fact_snapshot × dim_product）

| 指标 | 函数 | 定义 / 口径 | 业务用途 |
|------|------|------------|---------|
| 榜单价格统计 | `market_price_stats()` | 各品类均价/中位价/最低/最高 | 选品定价参考 |
| 评分统计 | `market_rating_stats()` | 平均评分 + ≥4.5 高分占比 | 市场进入门槛 |
| 热门商品榜 | `hot_products()` | 按评论数 TOP N，每个 ASIN 取最新快照 | 选品 |
| 价格带-需求关系 | `price_review_relationship()` | 各价格带平均评论数 | 需求热度分布 |
| 类目竞争度 | `category_competitiveness()` | 低价占比 + 高分占比 + 商品数 | 类目进入/退出决策 |
| 排名变化 | `rank_changes()` | 相邻两批采集的 position 差值 | 竞品动态监测 |

## 三、口径设计原则（面试直接讲这三条）

1. **收入只算 Shipped**：取消/待处理订单不计入 GMV，避免虚增；取消率单独监控
2. **评论数 = 销量代理**：亚马逊不公开真实销量，评论数是行业公认的需求热度代理指标
3. **比例可复核**：所有占比/环比指标保留分子分母计算过程，任何结论都能倒推验证
